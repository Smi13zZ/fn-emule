## 排查记录（两个值得记住的坑）

1. **零高整行宽的占位元素断不了行**：先插 `.vbreak { flex: 0 0 100%; height: 0 }`
   期望强制换行，实测无效 —— flex 里同 order 的项仍会被塞进当前行。改成直接给
   按钮设 `flex-basis: 100%` 才真正换行。
2. **`--dump-dom` 忽略 `--window-size`**：用它量手机布局得到的是 `innerWidth=780`
   的桌面布局，`matches640=false`。断言手机端行为必须用 `--screenshot`，或把测量值
   写进页面再截图读回。
