# 26.11.50「当前版本」标记

## 需求
设置-存储的安装包缓存里，「当前版本」这个标记太弱，跟背景分不开；改成实心反转色的药丸，
浅色主题近黑底白字、深色主题近白底深字，切主题时颜色跟着翻。

## 改动
| 文件 | 位置 | 改动 |
| --- | --- | --- |
| `app/web/index.html` | 存储表当前版本那一行 | `class="chip ok"` → `class="tagcur"`，`style="margin-left:6px"` 保留 |
| `app/web/style.css` | status chips 段之后 | 新增 `.tagcur` |
| `app/web/index.html` | `<link>` 的 `?v=` | 26.11.0 → 26.11.50 |
| `manifest` | `version` | 26.11.49 → 26.11.50 |

`.tagcur` 用 11px 字 / 3px 6px 内边距 / 5px 圆角，取 `--primary` + `--primary-fg`。
这两枚 token 在浅色主题是 #1c1c1c / #fafafa、深色主题是 #e5e5e5 / #1c1c1c，
所以主题切换不需要任何额外逻辑，属性一变颜色就地翻转。

没有动：`.chip` 基础类与 `.chip.ok / .chip.err` 变体、服务器表的「已连接」（那是连接状态，走绿色）、
i18n 文案、后端。

## 验证
- 探针页读真实 `index.html` 模板 + 真实 `style.css`（只注入 `<base>` 让相对路径指回产品目录），
  无头 Chrome 渲染后量像素：浅色 rgbrgb(28,28,28) / rgb(250,250,250)，深色 rgb(229,229,229) / rgb(28,28,28)，
  药丸 56×17（四个字），高度与目标一致。
- 跑真实的 Vue 挂载探针读 `getComputedStyle`：两主题下 `background`/`color` 就是 token 翻转，
  font-size 11px、圆角 5px，无 console.error、无未捕获异常。
- 手机宽度 390px 下药丸在同一行内，不换行、不溢出。
- `tools/check_structure.py` 对 9 个服务端模块 OK（本次未改 Python，回归确认）；前端 5 个 js `node --check` 全过。
