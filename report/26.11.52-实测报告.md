## 三、实测中发现并修复的 4 个问题

这些**全部是静态分析 + 9 项单元测试都没抓到的**，只有真机能暴露。

### 问题 1：`path` 字段语义判断反了（严重）

- **现象**：按审查建议改成「`path` 就是完整文件路径」后，`_prune_missing_shared` 判断目录存在就保留 → **已删文件永远无法剔除**，CP-6 完全失效。
- **真机实测**：`path='/vol1/@appshare/fn-emule/Incoming'`（**目录**），`name='localexists-test.txt'`，拼起来才存在。
- **修法**：新增 `_shared_file_path()` 统一拼接「目录 + 文件名」。
- **教训**：EC 字段名 `KNOWNFILE_FILENAME` 有误导性，实际装的是目录。

### 问题 2：空目录被当成「读不到」，保护逻辑反噬（严重）

- **现象**：共享目录被清空（用户删光文件）时，`scanned` 是空集，触发「目录读不到就别乱删」的保护 → 全部保留。
- **修法**：判据从「有没有扫到文件」改成「有没有**走通过**的共享根（`ok_roots`）」。
- **现在**：真正读不到（挂载掉线）才保守保留；目录正常但空则如实清空。

### 问题 3：prune 之后为空仍沿用旧缓存（严重）

- **现象**：`items` 被 prune 剔干净后，L1929 的「空列表不覆盖缓存」保护返回旧快照 → **恰好抵消 CP-6**。
- **修法**：区分两种情况——`raw_count>0`（引擎给了条目但被磁盘核对剔光）必须覆盖缓存；
  `raw_count==0`（引擎本轮没返回）才沿用旧快照。
- 单元测试补了 `4b)` 场景锁死。

### 问题 4：EC 客户端版本硬编码（遗留）

- **现象**：aMule 日志里一直显示 `fn-emule-panel 26.11.0`，与实际版本不符，排查时误导。
- **根因**：`ec.py` 里 `client_version="26.11.0"` 写死，与 manifest 无关（**改动前就存在**）。
- **修法**：新增 `_panel_version()`，优先读 `EMULE_VERSION` 环境变量、回退读 manifest。
- **实测**：日志已显示 `fn-emule-panel 26.11.52`。

## 五、部署与安装记录

### 安装命令（踩坑记录）

```bash
# 正确：-e 传的是「key=value 格式的文件路径」，不是 JSON、不是键值对
appcenter-cli install-fpk -e /tmp/emule-env.txt -v 1 /tmp/fn-emule-26.11.52.fpk
```

env 文件内容（**必须 key=value，JSON 会报 "env file are not format with key=value"**）：

```
wizard_backend_port=17581
wizard_tcp_port=4662
wizard_udp_port=4672
```

其它踩到的点：

- 不带 `-e` 直接装 → `Something wrong with environment variables`（wizard 有 3 个必填字段）
- 同版本覆盖安装 → `Application is installed`，必须先 `uninstall`
- `appcenter-cli start` 返回 `10500` 不代表失败，轮询 `status` 确认即可
- 面板实际部署路径是 `/usr/local/apps/@appcenter/fn-emule/`（**不是** `/var/apps/fn-emule`）
- web 目录：`/usr/local/apps/@appcenter/fn-emule/web/`

### 实测用的正确接口路径

```
/api/overview            概览
/api/transfers           任务（?type=download|upload|all）
/api/shared              共享列表（?force=1 跳缓存）
/api/shared/progress     扫描进度
/api/shared/reload       POST 触发重扫
/api/search/start        POST {"q":..., "kind":"server|kad|global", "method":"name"}
/api/search/<id>         搜索结果（含 warn / counts）
```

注意：`/api/transfers/download` **不存在**，正确写法是 `/api/transfers?type=download`。
