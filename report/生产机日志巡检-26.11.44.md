### 3.2 11-06 唯一的 1 条错误

```
2026-11-06 09:21:43 [error] 更新包校验失败：安装包无法解压：
Compressed file ended before the end-of-stream marker was reached
```

**这是升级 26.11.43 时下载到一半的安装包**（网络抖动截断）。面板的处理是对的：
校验失败 → 不安装 → 重新下载 → 09:21:47 记录「已下载并通过校验（9178617 字节）」→ 正常升级。

也就是说这条 error 是**自愈的**，用户端没有任何影响。但它确实说明一件事：
下载安装包时如果断流，用户会看到一条红色 error。**建议后续把「下载被截断 → 自动重试」的
过程降级成 info，只有重试用尽才报 error。** 这是我有意没在这次改的东西（属于体验优化，不是 bug）。
